# amimul1.github.io

Personal site of Amimul Ehsan Zoha. Plain HTML, CSS, and a little JavaScript, no build step.

- `index.html` holds all the content. Edit text there.
- `assets/style.css` has the colors (top of file) and layout.
- `assets/Amimul_Zoha_CV.pdf` is the linked CV. Replace the file to update it.

Pushing to `main` deploys through `.github/workflows/deploy.yml`.

Preview locally:

```bash
python3 -m http.server 8000
```
